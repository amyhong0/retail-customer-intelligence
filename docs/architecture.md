# 운영 환경 확장안

```text
S3 원천 데이터 → Glue 카탈로그 / Spark 정제 → 분석용 Parquet
                                            │
                                  SageMaker Feature Store
                                   ├───────────────┐
                              추천 모델        구매 예측 모델
                                   │                │
                            고객별 추천 목록     타겟 점수
                                   └───────┬────────┘
                                    API / 캠페인 실행 계층
                                            │
                                  CloudWatch / 모델 대시보드
```

운영 시에는 피처 생성 기준일의 정합성, 갱신 지연, 결측률을 점검합니다. 추천 모델은 카탈로그 적용 범위와 세그먼트별 Precision@K·Recall@K·NDCG@K를 추적합니다. 구매 예측은 ROC-AUC·PR-AUC·확률 보정 상태와 데이터 분포 변화를 감시합니다. 모델 교체 전에는 기존 모델과 새 모델을 비교하고, 캠페인 성과는 클릭만이 아니라 추가 구매와 이익을 무작위 실험으로 측정합니다.

선택형 인사이트 에이전트는 검증된 `summary.json`만 입력받아 제안 초안을 만듭니다. 핵심 지표 계산과 캠페인 실행은 결정론적 코드와 담당자의 승인 절차로 관리합니다.
